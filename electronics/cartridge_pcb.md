# Cartridge PCB — pin map

KiCad project: `electronics/cartridge_pcb/`, generated by
`electronics/tools/boards.py` (edit that, then run
`python3 electronics/tools/boards.py`). Why each part is there:
`docs/cartridge.md`.

Board: cartridge PCB, 81 × 7.9 × 1.6 mm, gold (ENIG) pads on the underside,
parts on top. Logic level: **3.3 V**. Powered from: the box, through the
contact pads. **3V3** feeds the chip and everything on 3.3 V; **5V** feeds
the LED chains, their level shifters, and the 5 V pins on the connectors.

Microcontroller: WCH CH32V006F8U6 (QFN-20, 3 × 3 mm). Pin functions are from
WCH's CH32V006 datasheet V1.8, table 2-1-1. "Remap" means the peripheral is
switched to those pins in firmware (AFIO register).

## Contact pads (underside, box side named)

| Pad | x (mm) | Net | Chip pin | Notes |
|---|---|---|---|---|
| 1 | −35 | +5V | — | LED chains, buffers, connector 5 V |
| 2 | −21 | GND | VSS (4), exposed pad | |
| 3 | −7 | PAD_TX (box → cartridge) | PC6 (13) via 100 Ω | USART1 RX (remap 6) or I²C SDA (remap 2) |
| 4 | +7 | PAD_RX (cartridge → box) | PC5 (12) via 100 Ω | USART1 TX (remap 6) or I²C SCL (remap 2). 100 kΩ to GND marks the cartridge present |
| 5 | +21 | PAD_SWIO | PD1 (15) via 100 Ω | 1-wire programming / debug |
| 6 | +35 | +3V3 | VDD (6) | |

All four non-ground pads have ESD protection (U2, SRV05-4).

One I²C peripheral: the Qwiic connector uses it on PC1/PC2. If the box link
is ever switched to I²C (remap 2 on PC5/PC6), the Qwiic port would need
software I²C on its pins.

## Connectors (top, JST-SH 1 mm, vertical)

| Ref | Default use | Pin 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| J1 | LED chain A | +5V | LEDA_OUT | GND | | | | | |
| J2 | LED chain B | +5V | LEDB_OUT | GND | | | | | |
| J3 | Qwiic (standard order) | GND | +3V3 | SDA | SCL | | | | |
| J4 | Display (e-ink module) | GND | +3V3 | SCK | MOSI | CS | DC | RST | BUSY |
| J5 | Spare pads (2 × 3 grid, 1.5 mm, bare) | PA2 | PD7 | PD5 | GND | +3V3 | +5V | | |

LED data (J1/J2 pin 2) is 5 V through a 74AHCT1G125 buffer (SC-70) and 330 Ω by
default. To use that pin as a plain 3.3 V GPIO: cut JP2 (or JP3) between pads
1 and 2, bridge 2 and 3.

## Solder jumpers

| Ref | Default | Change it to |
|---|---|---|
| JP1 | Bridged: I²C pull-ups (4.7 kΩ) on | Cut if Qwiic modules bring their own, or to repurpose PC1/PC2 |
| JP2, JP3 | 1–2: LED data buffered to 5 V | 2–3: direct 3.3 V GPIO (PD2 / PD3) |

## Not fitted (footprints only)

U5 (W25Q32JVSS, 4 MB; WP and HOLD tied to 3.3 V) and C6: image flash.
The LCD backlight switch (Q1, JP4, R10, R11) was dropped during layout to
make room: displays are e-ink, and LCD modules usually switch their own
backlight. J4 pin 8 is PA1 directly.
